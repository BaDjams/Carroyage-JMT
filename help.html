Guide d'utilisation

Retour à l'application

Bienvenue sur le guide du Générateur de Carroyage. Cette application est conçue pour vous fournir des outils cartographiques précis pour la planification, l'analyse et l'exportation. L'application est divisée en trois modes principaux.

Mode 1 : Carroyage CADO

Ce mode est le cœur de l'application. Il vous permet de générer un carroyage tactique (A1, B2, etc.) et une image imprimable à partir d'un point de référence.

Convertisseurs de Coordonnées

Avant de générer une grille, vous devez définir un point. Cette section vous aide à trouver et à convertir des coordonnées entre plusieurs formats :

  • GPS (Décimal ou DMS) : Le standard universel.
  • MERCATOR : Coordonnées projetées utilisées par de nombreux systèmes cartographiques web.
  • UTM : Un système de grille précis utilisé mondialement. Le format attendu est Zone Lettre Easting Northing (ex: 31 U 448252 5411943).

Cliquez sur "Convertir" pour mettre à jour tous les champs, ou "Voir sur la carte" pour centrer la carte sur ce point.

Configuration du Carroyage

Ici, vous définissez l'apparence et le comportement de votre grille. La compréhension des points suivants est essentielle :

  • Point de Référence : C'est le pivot de votre grille. Si vous appliquez une rotation (déviation), la grille tournera autour de ce point. Un cercle jaune le matérialise dans le fichier final.
  • Point d'Origine (A1) : C'est l'ancre de la grille, le coin de la case A1. Si vous choisissez "Origine (A1)" comme point de référence, les deux points sont confondus. Si vous choisissez "Milieu du carroyage", l'outil calcule la position de l'origine pour que votre point de référence soit au centre géométrique de la grille.

Génération d'Image (PNG/JPEG)

Cette fonction crée une image haute résolution de votre carroyage, superposée sur un fond de carte, prête à être imprimée ou partagée. Elle est activée sous certaines conditions pour garantir un rendu correct (Déviation à 0°, alignement de la grille).

  • Rendu dynamique : Le cartouche d'information, la boussole et la clé de subdivision s'adaptent automatiquement à la grille choisie.
  • Fonds de carte : Sélectionnez votre fond de carte préféré (Google, OSM, etc.) dans la liste déroulante.

Mode 2 : Grille UTM

Ce mode génère les lignes de la grille UTM officielle (carrés de 1km) pour une zone rectangulaire que vous dessinez sur la carte.

  • Multi-zone : La grille est générée correctement même si votre zone s'étend sur plusieurs fuseaux UTM.
  • Précision : Les lignes suivent la courbure de la Terre pour un alignement parfait dans les logiciels de SIG comme Google Earth.
  • Étiquettes Alignées : Les étiquettes de coordonnées sont placées directement sur les lignes pour une lecture facile.

Mode 3 : Exporter une Zone

Ce mode puissant vous permet de télécharger une image géoréférencée (PNG ou JPEG) d'une zone rectangulaire de votre choix, à un niveau de zoom précis.

  • Définition de la zone : Utilisez l'outil de dessin pour tracer un rectangle sur la carte.
  • Choix du rendu : Sélectionnez le fond de carte et le niveau de zoom qui vous intéressent. Le panneau d'information vous indique le nombre de tuiles à télécharger (limité à 2000 pour éviter les abus).
  • Import KML/KMZ (Optionnel) : Vous pouvez importer un fichier KML/KMZ contenant des polygones ou des tracés. L'outil dessinera automatiquement un rectangle qui englobe tous les éléments de votre fichier, vous faisant gagner du temps.
  • Téléchargement : L'outil assemble les tuiles pour créer une image unique de haute qualité.

Formats de Fichiers

  • KMZ : Format compressé pour Google Earth, idéal pour le carroyage CADO car il inclut les icônes personnalisées.
  • KML : Format standard pour Google Earth et Google Maps (sans icônes intégrées).
  • GeoJSON : Format universel pour les Systèmes d'Information Géographique (SIG) comme QGIS.
  • GPX : Format standard pour les appareils GPS (Garmin, etc.) et les applications mobiles de randonnée (OsmAnd, ViewRanger).

Introduction

Le Générateur CADO est un outil de cartographie opérationnelle. Il permet de créer des grilles de repérage alphanumériques (Ex: A1, B2) sur des fonds de carte, et d'exporter ces données pour l'impression ou l'intégration dans des GPS et Google Earth.

Mode Carroyage Rapide

Idéal pour créer rapidement une grille standardisée autour d'un point central (ex: une intervention, un lieu de rendez-vous).

Mode Export de Zone

Idéal pour préparer une carte d'une zone géographique spécifique (rectangle), avec ajout de points d'intérêt et téléchargement haute définition.

Mode 1 : Carroyage Rapide

1. Point de Référence et Géométrie

Ce mode génère une grille mathématique parfaite. Vous devez d'abord définir un point sur la carte (par recherche d'adresse, coordonnées GPS ou clic). Ce point sert d'ancre à votre grille.

Comprendre le "Point de Référence"

Option A : Milieu du carroyage

Le point que vous choisissez devient le centre exact de la grille.

Option B : Origine (A1)

Le point que vous choisissez devient le coin Sud-Ouest (Case A1).

2. La Rotation (Déviation)

Les villes et les routes ne sont pas toujours alignées sur le Nord géographique. Utilisez le curseur de rotation (sous la carte) pour aligner votre grille parallèlement à une route principale ou un bâtiment. Cela facilite le repérage sur le terrain : "Avance de 2 cases tout droit" devient plus logique que "Avance de 2 cases en diagonale".

  • Réglage grossier : Utilisez le curseur glissière.
  • Réglage fin : Utilisez les boutons ↺ et ↻ pour tourner degré par degré.

3. Formats de Grille

Q12 (Standard) Format Paysage / A4

17 colonnes (A-Q) x 12 lignes. C'est le format le plus courant pour l'impression A4.

Z18 Format A3

26 colonnes (A-Z) x 18 lignes. Couvre une zone plus large.

Z26 Carré Géant

26 colonnes x 26 lignes. Le maximum standard.

Note sur l'échelle : L'échelle (ex: 20m) définit la taille d'une seule case. Une grille Q12 à 20m fera donc 340m de large (17x20) par 240m de haut (12x20).

4. Formats d'Export

FormatUsage
Image (JPG/PNG) Pour impression papier ou envoi par email/MMS. L'image contient la carte, la grille dessinée par-dessus et un cartouche d'information.
KMZ Pour Google Earth. C'est un calque interactif qui se superpose à la planète en 3D. Contient les lignes et les labels.
GPX Pour GPS de randonnée (Garmin, TwoNav). Contient la grille sous forme de "Traces" et les intersections sous forme de "Waypoints".
GeoJSON Pour les logiciels SIG professionnels (QGIS, ArcGIS).

Mode 2 : Export de Zone

Ce mode ne part pas d'un point central, mais d'une zone rectangulaire que vous dessinez. Il sert principalement à créer des fonds de carte personnalisés.

1. Définir la zone

  • Dessin manuel : Utilisez l'outil à gauche de la carte pour tracer un rectangle.
  • Import KML : Si vous avez déjà un fichier KML avec une zone ou des points, importez-le. La carte zoomera automatiquement dessus.
  • Recherche : Tapez le nom d'une ville pour centrer la carte, puis dessinez.

2. Ajouter des Points d'Intérêt (POI)

Vous pouvez placer des icônes sur la carte avant de l'exporter. Ces icônes seront "imprimées" dans l'image finale ou incluses dans le fichier KMZ.

  1. Sélectionnez une icône dans la bibliothèque (vous pouvez filtrer par catégorie).
  2. Réglez la taille avec le curseur si besoin.
  3. (Optionnel) Donnez un nom au point.
  4. Cliquez sur "+ Activer l'ajout".
  5. Cliquez sur la carte à l'endroit désiré pour poser le point.

Astuce : Vous pouvez ajouter vos propres icônes perso via le bouton ⚙️ en haut de la page.

3. Les Calques (Surcouches)

Lors de l'export d'image ou de KMZ, vous pouvez choisir d'apposer une grille par-dessus la carte :

Grille UTM (Standard)

C'est le standard militaire et secours international.

  • Quadrillage kilométrique (cases de 1km x 1km).
  • Toujours orienté au Nord.
  • Les lignes principales (tous les 5km) sont plus épaisses.
  • Idéal pour la coordination inter-services.

Carroyage CADO (Tactique)

C'est une grille personnalisée adaptée à la zone.

  • Cases A1, A2, B1...
  • Taille des cases réglable (ex: 50m).
  • La grille couvre exactement la zone dessinée.
  • L'origine (A1) est le coin supérieur gauche (ou inférieur gauche selon réglage).

4. Qualité d'image & Upscaling

🚀

L'application utilise une technologie d'Upscaling Intelligent (Mise à l'échelle).

Si vous dessinez une petite zone sur la carte, une simple capture d'écran serait floue à l'impression. CADO télécharge automatiquement les tuiles de carte à la résolution maximale disponible et reconstitue une image géante (souvent supérieure à la 4K / 3840px).

Résultat : Vos cartes sont toujours nettes, même imprimées en grand format.

Paramètres : Gestion des Icônes

Cliquez sur le bouton ⚙️ en haut de la page principale pour ouvrir le gestionnaire.

  • Ajouter Glissez-déposez une image PNG directement dans la zone pointillée pour l'ajouter à votre bibliothèque personnelle.
  • Organiser Changez l'ordre des icônes ou renommez-les pour les retrouver plus facilement dans les listes.
  • Sauvegarder Vos icônes sont sauvegardées dans votre navigateur. Vous pouvez aussi utiliser les boutons Exporter JSON / Importer JSON pour transférer votre configuration sur un autre ordinateur.

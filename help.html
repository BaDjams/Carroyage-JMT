Guide d'utilisation CADO

Retour à l'application

Le Générateur de Carroyage CADO est un outil de cartographie tactique et opérationnelle. Il permet de créer des grilles de repérage précises et d'exporter des zones géographiques haute définition pour l'impression ou l'intégration dans des GPS et logiciels SIG.

Mode 1 : Carroyage Rapide

Ce mode génère une grille standardisée autour d'un point unique.

1. Définir le Point de Référence

  • Recherche : Utilisez la barre de recherche pour trouver une adresse (API gouvernementale BAN).
  • Coordonnées : Entrez des coordonnées (GPS, Mercator, UTM) et cliquez sur "Convertir".
  • Carte : Cliquez directement sur la carte.

2. Géométrie et Positionnement

Positionnement : Milieu vs Origine (A1)

1. Milieu du carroyage

La grille est centrée sur votre point.
La zone d'intérêt est au milieu.

2. Origine (A1)

Votre point devient le coin Sud-Ouest (A1).
La grille se déploie vers le Nord-Est.

Rotation (Déviation)

La rotation s'effectue toujours autour du Point de Référence choisi ci-dessus.

Rotation centrée

Si Réf = Milieu, la grille tourne sur elle-même.

Rotation sur l'Origine

Si Réf = Origine, la grille pivote comme une porte.

Formats de Grille

Q12 (Format Paysage / A4)

17 Colonnes (A à Q)
12 Lignes (1 à 12)

Z26 (Format Carré / Géant)

26 Colonnes (A à Z)
26 Lignes (1 à 26)

Mode 2 : Export de Zone

Ce mode est destiné à couvrir une zone géographique précise (rectangle) plutôt qu'un point. Il permet de télécharger des fonds de carte haute résolution.

1. Définir la Zone

  • Utilisez l'outil de dessin (carré) sur la carte de gauche.
  • Ou importez un fichier KML/KMZ existant : la carte zoomera automatiquement pour englober tous les points du fichier.

2. Ajout de Points d'Intérêt (POI)

Vous pouvez ajouter des marqueurs personnalisés qui seront incrustés dans l'image finale et le fichier KMZ.

Procédure :
  1. Sélectionnez une icône dans la grille (ou filtrez par catégorie).
  2. Entrez un nom (facultatif).
  3. Cliquez sur le bouton bleu "+ Ajouter un point".
  4. Cliquez sur la carte à l'endroit souhaité.

Note : Vous pouvez ajouter vos propres icônes via le bouton "⚙️" en haut de la page.

3. Génération et Qualité (Upscaling 4K)

Qualité d'impression garantie :
L'application vérifie automatiquement la résolution de l'image générée. Si la zone demandée produit une image trop petite pour être imprimée nettement (ex: petite zone, échelle fine), le logiciel effectue un Upscaling intelligent (lissage haute qualité) pour atteindre une définition minimale de 3840 pixels (4K).

4. Les Options d'Export

  • Générer KMZ (UTM) : Crée un fichier pour Google Earth avec une grille kilométrique UTM (standard militaire/secours).
  • Générer KMZ (CADO) : Crée un fichier Google Earth avec une grille CADO couvrant toute la zone dessinée.
  • Télécharger l'image : Crée une image unique (JPG/PNG). Vous pouvez cocher "Apposer le carroyage UTM" ou "Apposer le carroyage CADO" pour dessiner la grille directement sur l'image.

Formats de Fichiers

KMZ

Format Google Earth compressé. Contient la grille, les labels et les icônes personnalisées.

GeoJSON

Format ouvert pour les SIG (QGIS, ArcGIS). Idéal pour les professionnels.

GPX

Format GPS standard. Pour importer les points et la trace de la grille dans un GPS de randonnée.

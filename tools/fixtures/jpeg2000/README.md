`rgb-nir.jp2` est une image synthétique de 320 × 224 pixels, créée pour ces tests.
Les bandes valent `x % 251`, `y % 251`, `(x+y) % 251` et `170` (bande supplémentaire).
Compression sans perte, blocs de 320 × 128 px (96 lignes au bord), Web Mercator,
origine (0,224), pixel de 1 m.
Les pixels attendus permettent de vérifier les bords et la phase des ondelettes.
Aucune donnée satellite réelle n'est incluse.
